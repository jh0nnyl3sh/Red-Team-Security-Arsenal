# 🛡️ Red Team Security Arsenal

Siber güvenlik araştırmaları, sızma testi (pentest) betikleri ve etik hackerlık yol haritalarını içeren profesyonel siber güvenlik cephaneliğidir.

## ⚔️ Cephanelik İçeriği

- **📂 recon-and-osint:** Hedef belirleme ve pasif/aktif bilgi toplama araçları (Cyber Intel DB, Interrogator).
- **📂 brute-force:** Güvenlik açıklarını test etmeye yönelik kaba kuvvet saldırı betikleri.
- **📂 password-tools:** Parola üreticiler ve erişim kontrol sistemleri (PassGen, Gatekeeper).
- **📂 learning-path:** Siber güvenlik dünyasına giriş ve gelişim için teknik notlar (Hacking Road).

## ⚠️ Yasal Uyarı
Bu depodaki araçlar tamamen eğitim ve etik penetrasyon testleri için tasarlanmıştır. İzinsiz sistemlerde kullanılması yasal sorumluluk doğurabilir.
